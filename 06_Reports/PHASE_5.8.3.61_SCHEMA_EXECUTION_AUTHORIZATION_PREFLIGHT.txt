        the host is incorrect.

        and `SERVERPROPERTY('MachineName')` before piping the schema file.
   5. Script Guard Fail-Closed Action:
      - If connection lands on `HSWRMS` or `master` (e.g. if `-d` was omitted and
        `USE [HSWRMS_TEST]` failed):
        * Line 23 detects `DB_NAME() <> N'HSWRMS_TEST'`.
        * Line 26 executes `SET NOEXEC ON;`.
        * Line 27 executes `THROW 51000, ...;`.
        * Even if SQLCMD processes subsequent batches, `SET NOEXEC ON` forces SQL
          Server to compile but REFUSE EXECUTION of all subsequent DDL statements.
   6. Cross-Batch Autocommit Limitation:
      - `sqlcmd -b` halts on error, but DOES NOT roll back prior successful batches.
      - Therefore, `SET NOEXEC ON`, `THROW`, and `sqlcmd -b` are internal containment
        barriers, NOT substitutes for pre-execution target verification.
