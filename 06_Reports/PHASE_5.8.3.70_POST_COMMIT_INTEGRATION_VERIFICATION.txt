   2. Defect: `CreateAlaCarteRequest` Field Mismatch (P1)

      - Frontend (`fnbApi.ts` line 83): Sends `{ bookingId, deliveryLocation, deliveryTime, items[].specialNotes }`.

      - Backend: Expects `private String cancellationReason`.
      - Frontend (`fnbApi.ts` lines 126, 181): Sends `{ reason }`.
      - Impact: Jackson deserializes `cancellationReason` as `null`. When staff attempts to cancel
        an order in `PREPARING` or `READY` status, backend throws `CANCELLATION_REASON_REQUIRED`.
   4. Defect: `MealPrepEntryDto.id` Numeric Type vs String in Frontend (P1)
      - Backend: Serializes `id` as `Long` (e.g. `101`).
      - Frontend (`DiningContext.tsx` line 86, 265): Sets `id: dto.id` without string conversion.
        `extractNumericId(id)` executes `id.replace(/\D/g, '')`.
      - Impact: When updating or cancelling a remote backend order on KDS, browser throws
        `TypeError: id.replace is not a function`.
