3. RÀ SOÁT AN TOÀN VÀ NGUYÊN TẮC FAIL-CLOSED TRONG M6
================================================================================

3.1 PHÁT HIỆN LỖ HỔNG VÀ SỬA ĐỔI:
- Lỗ hổng trong BusinessParameterService.java:
  * Đoạn mã cũ:
    ```java
    if (!actor.admin()) {
        if (permissionService != null && !permissionService.userHas(actor.userId(), "S50", "U")) {
            audit.record(actor, "Update Business Parameter", "SystemConfiguration", key, AuditLogService.DENIED);
            throw new AccessDeniedException("Updating business parameters requires delegated S50:U permission.");
        }
        if (!config.isManagerEditable()) {
            audit.record(actor, "Update Business Parameter", "SystemConfiguration", key, AuditLogService.DENIED);
            throw new AccessDeniedException("This parameter is not covered by the delegated rights.");
        }
    }
    ```
  * Rủi ro bảo mật: Nếu BusinessParameterService được khởi tạo trong môi trường mà permissionService == null,
    biểu thức `permissionService != null && ...` trả về false. Khi đó, nếu tham số có `config.isManagerEditable() == true`,
    người dùng không phải admin (Manager) có thể cập nhật tham số cấu hình mà KHÔNG bị kiểm tra quyền S50:U!
    Đây là hành vi fail-open vi phạm nghiêm trọng nguyên tắc an toàn.
  * Sửa lỗi theo nguyên tắc Fail-Closed:
    ```java
    if (!actor.admin()) {
        if (permissionService == null || !permissionService.userHas(actor.userId(), "S50", "U")) {
            audit.record(actor, "Update Business Parameter", "SystemConfiguration", key, AuditLogService.DENIED);
            throw new AccessDeniedException("Updating business parameters requires delegated S50:U permission.");
        }
        if (!config.isManagerEditable()) {
            audit.record(actor, "Update Business Parameter", "SystemConfiguration", key, AuditLogService.DENIED);
            throw new AccessDeniedException("This parameter is not covered by the delegated rights.");
        }
    }
    ```
  * Kết quả: Nếu permissionService == null, mọi yêu cầu từ non-admin đều bị từ chối tuyệt đối (403 AccessDeniedException)
    và ghi vết kiểm toán trạng thái DENIED.

3.2 TEST BẰNG CHỨNG BỔ SUNG:
- BusinessParameterServiceTest.managerDeniedWhenPermissionServiceIsNullFailClosed:
  * Khởi tạo BusinessParameterService với `permissionService = null`.
  * Yêu cầu cập nhật từ ManagerActor -> Bị từ chối với AccessDeniedException.
  * Kiểm tra AuditLogRepository -> Xác nhận tồn tại bản ghi Action="Update Business Parameter",
    TargetDataType="SystemConfiguration", AccessStatus="DENIED", TargetRefId="refund_percentage".
  * Yêu cầu cập nhật từ AdminActor -> Cho phép thành công vì Admin không phụ thuộc quyền ủy quyền.
