3. AUTHORITATIVE PAYLOAD INSPECTION & ERROR ROOT CAUSE
--------------------------------------------------------------------------------
File Inspected: `05_Development/database/generated/HSWRMS_TEST_schema.sql` (1,223 lines)

3.1 Root Cause of Failure at Line 476:
    - At line 475, the script defines:
      ```sql
      CREATE UNIQUE NONCLUSTERED INDEX UQ_SpaTreatment_TreatmentCode
          ON dbo.SpaTreatment (treatment_code)
          WHERE treatment_code IS NOT NULL;
      GO
      ```
    - This is a filtered index (`WHERE treatment_code IS NOT NULL`).
    - Microsoft SQL Server requires the following session options to be set to `ON`
      when creating, modifying, or querying filtered indexes:
        * `QUOTED_IDENTIFIER`
        * `ANSI_NULLS`
        * `ANSI_PADDING`
        * `ANSI_WARNINGS`
        * `ARITHABORT`
        * `CONCAT_NULL_YIELDS_NULL`
      and `NUMERIC_ROUNDABORT` must be set to `OFF`.
    - When `sqlcmd` is executed without the `-I` (Enable Quoted Identifiers) switch,
      and when the script does not issue `SET QUOTED_IDENTIFIER ON;`, the session
      runs with `QUOTED_IDENTIFIER OFF`.
    - SQL Server raised Error 1934:
      `CREATE INDEX failed because the following SET options have incorrect settings: 'QUOTED_IDENTIFIER'.`
    - Because `sqlcmd` had `-b` enabled, it halted immediately at line 478.

3.2 Identification of All Filtered Indexes in Payload:
    There are four (4) filtered indexes throughout the authoritative schema:
    1. Line 476: `UQ_SpaTreatment_TreatmentCode` on `dbo.SpaTreatment(treatment_code)`
       `WHERE treatment_code IS NOT NULL`
    2. Line 909: `UX_PaymentTransaction_Reference` on `dbo.PaymentTransaction(transaction_reference)`
       `WHERE transaction_reference IS NOT NULL`
    3. Line 1166: `IX_User_AccountStatus_LockedAt` on `dbo.[User](account_status, locked_at)`
       `WHERE locked_at IS NOT NULL`
    4. Line 1175: `IX_AuditLog_TargetRefId` on `dbo.AuditLog(target_ref_id, created_at DESC)`
       `WHERE target_ref_id IS NOT NULL`

    All 4 indexes require `SET QUOTED_IDENTIFIER ON;` and `SET ANSI_NULLS ON;`
    to succeed.

3.3 Impact of Rerunning the Full Payload Blindly:
    - The first statement in `HSWRMS_TEST_schema.sql` is `CREATE TABLE dbo.[User]`.
